# Evil Seagull

A NeoForge mod for Minecraft 1.21.1 that enhances Alex's Mobs seagulls with new behaviors and visual effects.

## Third-Party Assets

The cosmic shader textures (`cosmic_0.png` ~ `cosmic_9.png`) and the original GLSL shader code are adapted from [RenderBlender](https://github.com/Nova-Committee/RenderBlender), licensed under LGPLv3. See `LICENSE-2` for the full license text.
